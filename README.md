# Context-Aware Adaptive Invisible Watermarking System

This project presents a context-aware adaptive invisible watermarking system based on Block-SVD watermark embedding.

The system:
- uploads host and watermark images,
- selects adaptive alpha values based on image domain,
- embeds invisible watermarks,
- applies attacks,
- extracts watermarks,
- evaluates PSNR, SSIM, BER, and correlation metrics.

Domains:
- Medical
- Satellite / GIS
- Cultural Heritage
- Natural Images

Technologies:
- Python
- Streamlit
- OpenCV
- NumPy
- Block-SVD Watermarking

Developed as part of PhD research on adaptive invisible watermarking systems.
